## 兼容与历史

1. 记录手机已安装包名、versionCode 与证书指纹，先停止采样并导出现有证据；不要卸载。
2. 对已授权取得的数据库**副本**做升级前后逐字段比对；不在个人手机运行 `StoreInstrumentedTest`（它是历史保留/清理压力测试）。
3. 本轮仍为 schema 2；核对旧 events 的 id/timestamp/elapsed/target/type/source/status/evidence、meta、source_state、source_gaps、collection_runs 和备份文件。新启动事件允许增加，旧行不得重写。接近容量上限时区分既有保留淘汰与迁移行为。
4. 签名不兼容则保持原安装与库，在专用模拟器安装基线APK与候选APK验证；不靠卸载解决。

## 24h 与耗电尚待实机

关闭监测 / v0.2.0 / 新候选三组，保持VPN、网络、使用方式、亮度、温度及充电条件可比。记录实际起止、采样成功/失败/延迟、最长间隔、每源gap、线程/PSS、库增长和系统电池统计。系统仅提供电量百分比时不换算精确mAh；模拟器不提供可用的手机耗电结论。休眠、强停、授权丢失都允许出现真实空白期，但不得补造成功记录。
